تثبيت التطبيق على الهاتف

قم بتثبيت التطبيق على شاشة هاتفك الرئيسية للوصول إليه بسرعة وبدون شريط المتصفح.

متطلبات تطوير وتحويل التطبيق (مثل متاجر التطبيقات):

  1. تحويل التطبيق إلى PWA حقيقي: إضافة ملف البيان (Manifest.json) لتعيين أيقونات التطبيق ووضعيته، وخدمة العمال (Service Worker) لدعم وضع العمل دون إنترنت (Offline Mode).
  2. رفع التطبيق إلى متجر جوجل بلاي (Google Play Console): عبر تغليف التطبيق بصيغة (Trusted Web Activity / TWA) أو باستخدام إطارات العمل مثل Capacitor و Cordova لربطه بخصائص الأندرويد الأصلية.
  3. نظام إشعارات حقيقي (Push Notifications): ربط النظام بـ (Firebase Cloud Messaging - FCM) لإرسال تنبيهات فورية للمستخدمة عن المواعيد والاشتراكات.
  4. قاعدة بيانات سحابية متكاملة (Cloud Database): ربط البيانات بـ (Cloud Firestore) لحفظ السجلات والمستويات سحابياً وعدم فقدانها بتغيير الهاتف.
  5. بوابات دفع إلكترونية أصلية (Salla API / In-App Purchases): دمج Google Play Billing أو ربط آلي مع متجر سلة للتحقق من حالة اشتراك العميل.
  6. تحسين تجربة الاستخدام (UX/UI): إضافة شاشات تحميل تفاعلية، دعم كامل للأجهزة اللوحية (Tablets)، والوضع الليلي التلقائي (Dark/Light Mode).
